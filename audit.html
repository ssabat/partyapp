Definitions

  • Current totals. Figures are the file as loaded now. This page does not store historical snapshots, so a past date cannot be selected.
  • Applicants are distinct applicantId values. Applications are individual records. One applicant can have several applications.
  • Amount to be funded is requested minus provided, only for approved and partially funded applications where both amounts are known and the remainder is positive. Pending is not a commitment. Declined and fully funded applications are excluded.
  • Currencies are never combined. There is no conversion policy.
  • Unknown country holds records with a blank country so application counts still reconcile.
  • Missing amounts stay unknown. They are not treated as zero.
